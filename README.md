# SOA - Cổng Thanh Toán Học Phí Trực Tuyến iBanking (TDTU)

> Đồ án môn Kiến trúc Hướng dịch vụ (SOA / Microservices) - Đại học Tôn Đức Thắng (TDTU)  
> 🌐 **Live Demo Frontend:** https://hocphitdtu.surge.sh

## Cấu trúc dự án
- `frontend/`: Ứng dụng Web iBanking hoàn chỉnh xây dựng bằng React 19 + Vite + Vanilla CSS hiện đại.
- `services/`: Các phân hệ Microservices backend (Auth & User, Tuition, OTP, Payment, API Gateway).

## Khởi chạy Frontend
```bash
cd frontend
npm install
npm run dev
```
Truy cập: `http://localhost:5173`
